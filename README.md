# BINAH 0.1.0 — Early Access

**BINAH is a minimalist time-awareness utility for Windows.**

It provides a quiet way to stay aware of time through a compact desktop display.

### Features
- Live clock and date.
- Year, month and week progress.
- Custom event countdowns.
- Static and moving ticker display modes.
- Appearance and transparency settings.
- Separate settings window.
- Local storage for preferences and saved events.

### Installation
1. Download `BINAH_0.1.0_x64-setup.exe`.
2. Double-click the installer.
3. Follow the installation instructions.
4. Launch BINAH from your Desktop or Start Menu.

No development tools are required.

### Platform
- Windows 10/11
- 64-bit (x64)

### Security notice
This early-access build is not code-signed. Windows may display an unknown-publisher or SmartScreen warning. Microsoft Defender custom scanning completed with no threat detections reported, but this is not an independent security certification.
